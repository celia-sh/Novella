## Config snapshot to remove

The pre-change public config contained:

- `platforms: ["android", "ios"]`.
- Android localization entries, splash image options, adaptive icon/package/
  version config, and Android signing/desugaring plugins.
- `novella-ui` registration for both Android and iOS.
- Android media permissions generated by the media-library plugin.
- The combined splash plugin's Android and iOS mods.

The iOS values to preserve are the bundle identifier, build number, tablet
support, `Novella.icon`, status-bar ownership flag, Chinese localizations,
Readium pods, ccache/build-properties options, splash appearance, and image
save permission text.

## Legacy settings contract

The persisted key remains `novella.settings.v1`. Existing records may contain
`useSystemColor` and `oledBlack` from the former Android settings UI. The new
React-free decoder must:

1. start from the current defaults;
2. validate and copy only current allowlisted fields;
3. ignore both removed fields and any other unknown keys;
4. preserve valid unrelated settings; and
5. serialize only the current public snapshot on the next write.

The public `AppSettings` snapshot must contain neither removed field. Dark iOS
book-detail OLED behavior remains an internal theme choice, not a setting, so
an old `oledBlack: false` value must not disable that behavior. This contract
is recorded in `.trellis/spec/frontend/state-management.md`.
